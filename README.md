DonationMatch
Give What You Have. Match What They Need.
DonationMatch is a web-based donation platform designed to connect donors with organizations that need assistance.
Features
User Registration
User Login and Logout
Role-Based User Accounts
Donor and Organization Roles
User Dashboard
Admin Dashboard
User Profile Management
PostgreSQL Database Integration
Technologies Used
Python
Django
PostgreSQL
HTML
CSS
JavaScript
